Utilities

Feature Importance

MichiBoost.feature_importance — Function
feature_importance(model::MichiBoostModel) -> Vector{Pair{Symbol, Float64}}

Compute feature importances based on split frequency across all trees.

Each pair is feature_name => percentage, sorted descending. Percentages sum to 100. Features never used in any split get 0.

feature_importance(model) -> Vector{Pair{Symbol, Float64}}

Return feature importances as feature_name => percentage pairs, sorted by importance (descending). Importance is based on how often each feature was chosen for a split across all trees.

Example

fi = feature_importance(model)
# [:num_1 => 62.5, :num_3 => 25.0, :cat_1 => 12.5]

Model State

MichiBoost.is_fitted — Function
is_fitted(model) -> Bool

Return true if model has been trained (i.e., fit! has populated its underlying MichiBoostModel), false otherwise. Use it to guard prediction or inspection calls against untrained wrappers.

Example

model = MichiBoostRegressor(; iterations=100)
is_fitted(model)              # false
fit!(model, X, y)
is_fitted(model)              # true

Hyperparameter Access

MichiBoost.get_params — Function
get_params(model) -> Dict{Symbol,Any}

Return a copy of the hyperparameters stored on the wrapper. The returned Dict is independent of the wrapper's internal state — mutating it will not affect model. Use set_params! to update them.

Example

model = MichiBoostRegressor(; iterations=100, depth=4)
get_params(model)   # Dict(:iterations => 100, :depth => 4, :loss_function => "RMSE")
MichiBoost.set_params! — Function
set_params!(model; kwargs...) -> model

Update hyperparameters on the wrapper, returning model for chaining. New keys are added; existing keys are overwritten. Changes only take effect on the next fit! call — already-trained models are not retrained.

Example

model = MichiBoostRegressor(; iterations=100)
set_params!(model; iterations=500, depth=4)
fit!(model, X, y)   # uses the updated values

Early-Stopping Inspection

MichiBoost.get_best_iteration — Function
get_best_iteration(model) -> Int

Return the iteration that achieved the best eval-metric value during early stopping (1-indexed). If early stopping was not active, returns the total number of iterations actually completed (i.e., length(model.trees)).

MichiBoost.get_best_score — Function
get_best_score(model) -> Union{Float64,Nothing}

Return the eval-metric value at get_best_iteration. Returns nothing when early stopping was not active (no eval_set / early_stopping_rounds supplied at fit time).

Truncation

MichiBoost.shrink — Function
shrink(model, n::Integer) -> model

Truncate the model's ensemble to its first n trees in place. Pure metadata change — predictions made after shrink use only the retained trees. Useful for selecting a prefix of an early-stopped model (e.g., to roll back to the get_best_iteration snapshot) and for snapshot / resume workflows.

n must satisfy 0 <= n <= length(model.trees). The model is returned for chaining; get_best_iteration / get_best_score are preserved as recorded during training and may now exceed length(model.trees).

Example

clf = MichiBoostClassifier(; iterations=200, early_stopping_rounds=10, ...)
fit!(clf, train_pool; eval_set=val_pool)
shrink(clf, get_best_iteration(clf))   # roll back to the ES best

Per-Iteration Metric Evaluation

MichiBoost.eval_metrics — Function
eval_metrics(model, pool::Pool; metrics) -> Dict{String,Vector{Float64}}

Evaluate one or more metrics on a labelled Pool at every boosting iteration. Mirrors CatBoost's eval_metrics: returns a dictionary keyed by canonical metric name, with each value a vector of length n_iterations giving the metric's value after i trees have been added.

metrics is a vector of Metrics.* tag types and/or CatBoost-style strings (e.g. [Metrics.AUC, "Logloss"]). Each metric must be valid for the model's task (regression / binary / multi-class), or it errors.

Example

result = eval_metrics(model, val_pool; metrics=[Metrics.AUC, Metrics.Logloss])
result["AUC"]      # Vector{Float64}, length == length(model.trees)
result["Logloss"]

SHAP Feature Attributions

MichiBoost.shap_values — Function
shap_values(model::MichiBoostModel, pool::Pool) -> Array

Compute SHAP feature attributions for each sample in pool.

Returns:

  • Regression / Binary: Matrix{Float64} of shape (n_samples, n_features).
  • Multiclass: Array{Float64,3} of shape (n_samples, n_features, n_classes).

Each row sums exactly to raw_prediction - E[raw_prediction], where the expectation is taken under a uniform distribution over tree leaves.

shap_values(model, data; cat_features=nothing) -> Array

Compute SHAP feature attributions for each sample.

  • Regression / Binary: returns Matrix{Float64} of shape (n_samples, n_features).
  • Multiclass: returns Array{Float64,3} of shape (n_samples, n_features, n_classes).

Each row sums approximately to prediction - mean_prediction.

Example

shap = shap_values(model, X_test)
# shap[i, j] is the contribution of feature j to sample i's prediction

Model Persistence

MichiBoost.save_model — Function
save_model(model, filepath::AbstractString)

Serialize a trained model to disk using Julia's Serialization module.

Works with both wrapper types (MichiBoostRegressor, MichiBoostClassifier) and raw MichiBoostModel objects.

See also load_model.

MichiBoost.load_model — Function
load_model(filepath::AbstractString) -> MichiBoostModel

Load a model previously saved with save_model.

Example

save_model(model, "my_model.jls")
loaded = load_model("my_model.jls")
predict(loaded, X_test)  # works with the raw MichiBoostModel
